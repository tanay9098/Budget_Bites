# Cooking on induction cooktops

Induction cooktops only heat cookware with a magnetic base.

## Safety and adaptation
- Use only induction-compatible cookware, including the pressure cooker; check the base is marked induction-compatible.
- Begin on a medium power setting and raise it only if needed; induction heats faster than many gas burners.
- A pressure cooker can be used on induction if it is an induction-base model, with timings similar to gas.
