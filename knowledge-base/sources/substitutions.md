# Ingredient substitution guide

Each entry says what is swapped, whether the diet class is preserved and what changes. Only the substitutions below are recorded. If an ingredient is not listed here, no evidence-backed substitute is available and the agent must say so.

## Supported substitutions
- Moong dal can replace toor dal. Both are vegetarian pulses; moong dal cooks faster, so reduce the cooker time to about 3 whistles.
- Toor dal can replace moong dal in khichdi. Cooking takes longer, so allow about 4 whistles.
- Paneer can replace eggs in a bhurji-style dish. The result is vegetarian but contains dairy, so it fails a dairy exclusion.
- Soy chunks can replace chicken in a curry. The result is vegetarian but contains soy.
- Besan chilla batter can replace eggs as the protein in a savoury breakfast. It is vegetarian and egg-free.

## Not covered
- No evidence-backed substitute for onion is recorded in this guide.
- No evidence-backed substitute for tomato is recorded in this guide.
