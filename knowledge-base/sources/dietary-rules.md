# Dietary classification rules

## Vegetarian mode
- Eggs, chicken, meat, fish and seafood are never allowed.
- Dairy (milk, curd, paneer, ghee, butter) is allowed unless the user excludes it.

## Non-vegetarian mode
- Both vegetarian recipes and recipes with eggs, chicken or fish are allowed.
- Specific user exclusions, such as no eggs, still apply.

## Clarification needed
- Packaged masalas, stock cubes and gelatine-set desserts can contain animal-derived ingredients; ask the user to check labels.
- Shared utensils or cooking oil with non-vegetarian food are a cross-contamination concern that strict vegetarians may care about.
